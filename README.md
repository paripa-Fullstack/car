# Premium Auto Haus - Frontend Project

## Описание проекта
Премиальный фронтенд-каркас сайта автосалона / сети автохаусов с современной анимацией и UX.

## Технологический стек

### Core
- **HTML5** - семантическая разметка
- **CSS3** - современные стили с CSS Custom Properties
- **Vanilla JavaScript** - без фреймворков
- **PHP** - шаблонная сборка (include/require)

### Библиотеки
- **GSAP** - премиальные анимации
- **Swiper.js** - слайдеры
- **GLightbox** - галереи
- **Intersection Observer** - анимация при скролле

### НЕ используется
- ❌ React/Vue/Angular
- ❌ Bootstrap/Tailwind
- ❌ jQuery

## Установка и запуск

### Требования
- PHP 7.4+
- Любой современный браузер

### Локальный запуск

```bash
# Клонируйте репозиторий
cd /workspace

# Запустите встроенный PHP сервер
php -S localhost:8000

# Откройте в браузере
http://localhost:8000
```

## Особенности проекта

### Дизайн-система
- Единая система цветов через CSS Variables
- Типографика с использованием Inter и Playfair Display
- Премиальная цветовая палитра (глубокий синий + золотой акцент)
- Продуманная система отступов и размеров

### Анимации
- Reveal-анимации при скролле
- Плавные hover-эффекты
- Анимированные счетчики KPI
- Premium transitions между состояниями
- Поддержка prefers-reduced-motion

### Адаптивность
Брейкпоинты:
- 1440px+ (Extra Large Desktop)
- 1200px (Large Desktop)
- 992px (Desktop)
- 768px (Tablet)
- 576px (Mobile)
- 360px (Small Mobile)

### Производительность
- Lazy loading изображений
- Оптимизированные анимации
- Минимальный reflow/repaint
- Critical CSS inlining
- Defer для скриптов
